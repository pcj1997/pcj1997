## About Me

我是一个偏产品思维的工程师，擅长把真实工作场景中的复杂问题，收敛成可以直接使用的软件工具。

我的关注点不只是完成一个功能，而是让系统具备可观测性、可维护性和稳定的交付体验。从底层协议分析，到桌面工具、Web 控制台，再到 AI 驱动的工作流，我喜欢处理那些跨越多个技术层次的问题。
